# GREEN-API Messenger

Веб-интерфейс для отправки и получения текстовых сообщений в **Telegram** через [GREEN-API](https://green-api.com/telegram/).
Тестовое задание на должность «Фронтенд-разработчик React».

> Статус: в разработке. Демо, скриншоты и видео появятся по готовности.

## Возможности

- Вход по `idInstance` и `apiTokenInstance` инстанса GREEN-API.
- Новый чат по номеру телефона получателя.
- Отправка текстовых сообщений (`SendMessage`), получение ответов через HTTP API (`ReceiveNotification` / `DeleteNotification`).
- История переписки, список чатов, адаптивная вёрстка по мотивам веб-версии Telegram.

## Локальный запуск

Нужны Node.js 22+ и pnpm 10+.

```bash
pnpm install
pnpm dev
```

Приложение откроется на http://localhost:5173. Остальные команды: `pnpm build`, `pnpm lint`, `pnpm test`.

## Подготовка инстанса GREEN-API

Нужен инстанс GREEN-API для **Telegram** (подойдёт бесплатный тариф «Разработчик») с подключённым Telegram-аккаунтом.

1. **Создать и авторизовать инстанс** в [личном кабинете](https://console.green-api.com): QR-код инстанса → в Telegram:
   Настройки → Устройства → Подключить устройство. После запуска инстанс может до нескольких минут быть в состоянии `starting`.
2. **Включить уведомления.** У нового инстанса они **выключены**, и без этого шага приложение не получит ни одного сообщения.
   В настройках инстанса: `incomingWebhook` (Получать уведомления о входящих сообщениях и файлах), `outgoingWebhook` (Получать уведомления о статусах отправленных сообщений), `outgoingMessageWebhook` (Получать уведомления о сообщениях, отправленных с телефона), `outgoingAPIMessageWebhook` (Получать уведомления о сообщениях, отправленных с API) — «да»;
   `webhookUrl` (Адрес отправки уведомлений (URL)) — **пусто** (иначе уведомления уходят на вебхук, а не в очередь, которую читает приложение). Настройки применяются до ~5 минут.
   Если что-то не так, приложение предупредит об этом на экране входа.
3. **Войти в приложение** с `idInstance` и `apiTokenInstance` из личного кабинета.

Особенности Telegram, о которые легко споткнуться:

- **Получатель находится по номеру, только если он это разрешил:** в его Telegram — Настройки → Конфиденциальность → Номер телефона →
  «Кто может найти меня по номеру» = «Все». Иначе приложение ответит, что аккаунт не найден.
- **Новый Telegram-аккаунт не может первым писать незнакомым** — антиспам Telegram, сообщение помечается «не доставлено» с причиной `peer flood`.
  Достаточно, чтобы получатель написал первым (или чтобы аккаунты были друг у друга в контактах).
- **Лимиты тарифа «Разработчик»:** 3 чата и 100 поисков по номеру в месяц, сброс 1-го числа. Подробнее — [тарифы GREEN-API](https://green-api.com/telegram/docs/about-tariffs/).
