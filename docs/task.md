# Тестовое задание

Тестовое задание на должность «Фронтенд-разработчик React» в GREEN-API. Текст ТЗ — дословно, ниже — как он трактуется в проекте.

## Текст задания

В рамках тестового задания требуется разработать пользовательский интерфейс для отправки и получения сообщений в MAX
(если вы не можете выполнить тестовое задание для мессенджера MAX, можете сделать для WhatsApp или Telegram).

Время на выполнение задания: **5 дней**.

**Требования:**

1. Требуется разработать пользовательский интерфейс для отправки и получения сообщений в MAX.
2. Требуется использовать сервис **GREEN-API** https://green-api.com/max
3. Требуется реализовать отправку и получение только текстовых сообщений.
4. Требуется за прототип интерфейса взять внешний вид чата https://web.max.ru/
5. Требуется реализовать интерфейс максимально простым с минимальным набором функций.
6. Требуется отправку сообщений реализовать методом https://green-api.com/v3/docs/api/sending/SendMessage/
7. Требуется получение сообщений реализовать методом https://green-api.com/v3/docs/api/receiving/technology-http-api/
8. Требуется использовать технологию **React**.

**Ожидаемый результат:**

- Пользователь переходит на сайт чата и вводит свои учётные данные из системы GREEN-API (`idInstance`, `apiTokenInstance`).
- Пользователь вводит номер телефона получателя и создаёт новый чат.
- Пользователь пишет текстовое сообщение и отправляет его получателю в MAX.
- Получатель отвечает на сообщение в мессенджере MAX.
- Пользователь видит ответ получателя в чате.

**Результат** выполнения отправить на hr@green-api.com, тема «Тестовое задание на должность - Фронтенд разработчик React»:

1. Резюме (pdf, с телеграмом для связи).
2. Ссылка на репозиторий GitHub.
3. Ссылка на инструкцию для локального запуска проекта.
4. Ссылка на сервис в интернете (желательно).
5. Ссылка на скриншоты / видео-презентацию (при наличии).

## Трактовка в проекте

- **Мессенджер — Telegram** (разрешено ТЗ; аккаунта MAX нет) — [ADR 0001](decisions/0001-telegram-instead-of-max.md).
  Ссылки на методы — их Telegram-версии: [SendMessage](https://green-api.com/telegram/docs/api/sending/SendMessage/),
  [HTTP API получения](https://green-api.com/telegram/docs/api/receiving/technology-http-api/). Прототип внешнего вида — веб-версия Telegram.
- **Не заменяется «более удачным» решением:** отправка — только `SendMessage`; получение — только HTTP API
  (`ReceiveNotification` + `DeleteNotification`), не вебхук; на входе — только `idInstance` и `apiTokenInstance`.
- **«Минимальный набор функций»:** всё сверх сценария выше — в [BACKLOG.md](../BACKLOG.md), а не в основной работе.
