# Тесты

- **vitest** — чистая логика без DOM: разбор уведомлений, нормализация номера, слияние и дедуп сообщений.
- **Где лежат unit-тесты** — в папке `__tests__/` рядом с проверяемым модулем, в любой папке, включая папки компонентов
  (`src/utils/helpers/__tests__/dateFormat.test.ts`, `Avatar/__tests__/_helpers.test.ts`); не вперемешку с кодом. Тест, проверяющий несколько модулей
  одной области, — в `__tests__/` ближайшей общей папки. Общие тестовые утилиты (хранилище в памяти и т. п.) — в `__tests__/` самой нижней папки,
  покрывающей всех их потребителей (та же лестница, что в `structure.md`); импортируются напрямую, без barrel.
- **Playwright** — e2e со стабом GREEN-API через `page.route` и фикстурами уведомлений; воспроизводим без кредов.
  Живые проверки на реальном инстансе — только с кредами из `.env.local`.
