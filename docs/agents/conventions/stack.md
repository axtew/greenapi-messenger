# Стек

Добавление зависимости — с разрешения владельца. Случаи, где тянет взять библиотеку, а нельзя:

- **Формы** — собственный хук `useForm` проекта. Не добавлять `react-hook-form`, `formik` и подобные.
- **Серверное состояние** — TanStack Query. Не заводить параллельный store (Context с данными, Zustand, Redux) для того, что приходит из API.
- **Валидация внешних данных** — `zod`.
- **HTTP** — `fetch` через тонкий клиент GREEN-API. Не добавлять `axios` и SDK GREEN-API.
- **UI-библиотек нет** — компоненты проекта на styled-components.
