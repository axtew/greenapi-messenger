# Стили

styled-components. Локальные стили компонента — в `_styles.ts` рядом с ним. Styled-компоненты — с префиксом `S` (`SContainer`, `SHeader`).
UI-библиотек нет: все примитивы — компоненты проекта.

## Правила CSS

- **Цвета, отступы, радиусы, типографика — токены темы.** Литеральный hex — только если цвета действительно нет в теме **и** план явно помечает его
  как исключение. Значение из референса сначала сопоставляется с токеном.
- **Обычный поток вместо `position: sticky` / `fixed`.** Следовать ближайшей существующей раскладке; `sticky` / `fixed` — только когда задача явно
  требует закрепления при прокрутке или этого действительно требует раскладка, а не по привычке «это же верхняя панель».
- **Чисто декоративные элементы — псевдоэлементом.** Элемент без семантики и роли доступности, целиком определяемый состоянием родителя
  (например, подчёркивание вкладки), — через `::before` / `::after`, а не отдельным узлом. Отдельный узел оправдан, если у него своё поведение,
  его надо измерять отдельно или он структурный.

## Адаптив и платформа

- На широком экране — две колонки (список чатов + переписка), на узком — один экран с переходом «назад».
- `100dvh` (не `100vh`), `env(safe-area-inset-*)`, тап-цели ≥ 44px.
- Поле ввода — `font-size: 16px`: иначе Safari на iOS зумит страницу при фокусе. Это ограничение платформы, а не размер из шкалы, — оставлять с комментарием.
- Тема — только светлая (тёмная — в `BACKLOG.md`).
