# Роуты и страницы

Роутинг — TanStack Router в **code-based** режиме: дерево роутов написано явно, без кодогенерации и `routeTree.gen.ts`.

- `src/routes/` — только дерево: константы путей (никаких строковых литералов путей в компонентах), роуты, сборка роутера, layout-обёртки.
- **Guard авторизации — `beforeLoad` защищённого layout-роута**, а не компонент-обёртка: срабатывает до рендера, защищённый экран не мелькает.
- `src/pages/<Name>Page/` — сам экран по конвенциям компонентов; части страницы — в её `_internal/`.
