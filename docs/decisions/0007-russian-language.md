# 0007. Язык репозитория — русский

- Статус: принято
- Дата: 2026-10-04

## Контекст и проблема

ТЗ и вакансия — на русском, английский в требованиях не заявлен. Часть инструкций для агентов была на английском (общие конвенции автора, которые он переносит между проектами), часть — на русском; смешение языков, в том числе внутри одного файла, мешает читать проект.

## Решение

**Всё на русском:** README, документация, ADR, инструкции для агентов (`AGENTS.md`, `docs/agents/`), комментарии в коде, проза в `plans/`.
По-английски остаются только технические имена (идентификаторы, имена файлов, API, библиотеки), имена файлов ADR и заголовки, статусы и ключи из шаблонов пайплайна, которые читают скиллы.

## Последствия

- Конвенции этого репозитория расходятся по языку с исходными конвенциями автора в других проектах. Проект не планируется сопровождать после сдачи, синхронизация не нужна.
