# 0002. Без бэкенда: браузер ходит в GREEN-API напрямую

- Статус: принято
- Дата: 2026-10-03

## Контекст и проблема

Приложению нужно вызывать GREEN-API. Если API не разрешает кросс-доменные запросы, нужен прокси-сервер.

## Рассмотренные варианты

1. Прямые запросы из браузера.
2. Прокси на Cloudflare Worker.

## Решение

**Прямые запросы.** Проверено curl'ом: `api.green-api.com` и хосты инстансов отвечают `Access-Control-Allow-Origin: *`
и разрешают `GET, POST, DELETE` с `Content-Type`. Прокси ничего не добавляет, кроме точки отказа.

## Последствия

- Приложение — чистая статика.
- `apiTokenInstance` хранится в браузере (localStorage) и виден в DevTools. Для тестового это допустимо;
  в продукте токен держал бы бэкенд, а браузер получал бы сессию.
- Получение — HTTP API (long-polling), вебхук невозможен: его некому принимать.
