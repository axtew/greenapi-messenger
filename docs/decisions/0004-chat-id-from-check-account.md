# 0004. chatId только из `checkAccount` и уведомлений

- Статус: принято
- Дата: 2026-10-03

## Контекст и проблема

Пользователь вводит номер телефона. GREEN-API принимает `номер@c.us`, но в Telegram chatId — числовая строка,
и входящие уведомления приходят именно с ней.

## Решение

**Номер → `checkAccount` → числовой chatId**; дальше везде только он. Неизвестный chatId из входящего — новый чат.

## Последствия

- Чат, созданный по номеру, совпадает с ответами собеседника.
- На тарифе «Разработчик» один человек занимает один слот из трёх, а не два (разные форматы id считаются разными чатами).
- `exist: false` — нет аккаунта **или** номер скрыт настройками приватности: интерфейс говорит об этом прямо.
- `checkAccount` на тарифе «Разработчик» — 100 вызовов в месяц: chatId по номеру кэшируется.
