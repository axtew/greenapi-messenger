# 0001. Telegram вместо MAX

- Статус: принято
- Дата: 2026-10-03

## Контекст и проблема

ТЗ просит интерфейс для MAX, но разрешает WhatsApp или Telegram, если с MAX выполнить нельзя. Аккаунта MAX у автора нет.

## Решение

**Telegram.** У GREEN-API для Telegram тот же формат запросов, те же `SendMessage` и HTTP API получения, что и для MAX, —
требования ТЗ выполняются без изменений. Тестовый аккаунт Telegram регистрируется отдельно.

## Последствия

- Документация — Telegram-продукт GREEN-API: https://green-api.com/telegram/docs/
- chatId в Telegram — числовая строка (см. ADR 0004); `checkAccount` может не найти человека, скрывшего поиск по номеру.
- Переход на MAX — смена хоста/инстанса и проверка форм уведомлений; архитектура не меняется.
