# 0005. Один потребитель очереди: Web Locks

- Статус: принято
- Дата: 2026-10-03

## Контекст и проблема

Очередь уведомлений у инстанса одна. Две вкладки — два цикла получения, которые делят её: каждое сообщение попадёт только в одну из них.
В dev-режиме React StrictMode монтирует эффекты дважды — та же проблема внутри одной вкладки.

## Решение

- Поллит только вкладка, захватившая Web Lock (`navigator.locks`); остальные ждут, пока лидер закроется.
- Старт цикла идемпотентен; выход из аккаунта прерывает его (AbortController).

## Последствия

- Новые сообщения видны только во вкладке-лидере. Раздача событий остальным (BroadcastChannel) — в `BACKLOG.md`.
